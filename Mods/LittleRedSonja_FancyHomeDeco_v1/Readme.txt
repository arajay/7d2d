-- Fancy Home Deco -- 7DTD mod -- by LittleRedSonja --


This mod is compatible with V1, V2, V3 and later versions of the game. 


Installation Instructions:

Extract the downloaded zip into your 7D2D Mods folder (create one if it does not exist).

To verify you have installed the mod correctly, the ModInfo.xml file should be located at Mods\LittleRedSonja_FancyHomeDeco_v1\ModInfo.xml relative to your 7D2D install folder.

This mod is Server-Side-Friendly (for multiplayer the mod needs to be installed only in the server, player do not need to install it).


Since more and more things are added to the mod I have removed the folder with preview pictures from the download, because it was getting really big. You can see all the pictures in Nexus mods.
